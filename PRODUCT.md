# PMR launch media

<!-- impeccable:product-schema 1 -->

## Platform

web

This record governs the React/Remotion launch media in media/video. PMR itself is a native Rust CLI for macOS and Linux.

## Users

Developers and coding agents managing local services and background commands.

## Product Purpose

Start named processes, inspect their logs and JSON state, and recover from process failures.

## Capabilities and Constraints

The repository is private under liammendes/pmr. Launch copy is draft only. PM2 compatibility is partial. Benchmark claims must identify the operation, comparator, samples and hardware. Raspberry Pi camera supervision is a use case; physical Pi hardware has not been tested.

## Brand Commitments

Liam Mendes personal project only. Direct, warm, professional writing. The current identity uses the same deep blue gradient for the PMR lettering and terminal icon. Finish the icon in Apple Icon Composer. The official Liam Mendes vector logo follows Liam’s Paper layouts: bottom-right in the film, top-left in the poster. All supporting composition typography is black (#000000). The intro wordmark, headline and description share a 100 px left edge; the poster centres its wordmark and copy. Keep the artwork free of URL and native-supervisor footers.

## Evidence on Hand

Real native-terminal dashboard captures in docs/assets. Reproducible benchmark data in benchmarks/results/2026-10-15-m1-max. Camera demo uses synthetic frames and a deliberate process crash.

The 40-second launch film also shows scripted agent events through real `pmr logs`, followed by real local report, archive and checksum workers. The agent scene illustrates process supervision; it is not an AI-model performance demonstration.
