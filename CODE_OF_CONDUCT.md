# Code of Conduct

Be considerate, specific and constructive. Critique the code or idea, not the person. Make room for people with different backgrounds and levels of experience.

Harassment, threats, discriminatory abuse, sexual harassment and publishing someone else's private information are not welcome. These expectations apply to this repository and its project spaces.

Maintainers may edit or remove contributions, close discussions or restrict participation when needed to protect the community. Reports will be considered fairly and shared only with people who need to handle them.

Report a concern privately to hello@liammendes.co.uk. Include enough context to understand what happened; avoid posting another person's private details in a public issue.
